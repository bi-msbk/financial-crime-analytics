NFR-001 — Data quality

Critical analytical fields should meet defined completeness and validity thresholds.

NFR-002 — Reproducibility

The analytical process should be reproducible from the provided source/generated data.

NFR-003 — Auditability

Each analytical metric should be traceable to its source fields and transformation logic.

NFR-004 — Explainability

Fraud indicators and risk scores should be interpretable.

NFR-005 — Privacy

No real customer personally identifiable information will be used.

NFR-006 — Performance

SQL queries should be designed with analytical performance in mind.

NFR-007 — Documentation

Business logic, assumptions, data definitions and analytical methodology must be documented.

NFR-008 — Version control

All analytical code should be maintained in Git.

NFR-009 — Maintainability

SQL/Python should be modular rather than a single large script.
