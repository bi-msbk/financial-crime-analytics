# Acceptance Criteria

**AC-001**  
Fraud exposure metrics can be calculated from the analytical dataset.

**AC-002**  
Fraud trends can be analysed over time.

**AC-003**  
Fraud can be segmented by transaction channel, merchant, geography and device.

**AC-004**  
Existing fraud controls can be evaluated against confirmed fraud outcomes.

**AC-005**  
Confirmed fraud cases not detected by existing controls can be identified.

**AC-006**  
High-risk transactions can be prioritised using documented analytical indicators.

**AC-007**  
Executive and investigator dashboards are available.

**AC-008**  
All dashboard KPIs can be traced to documented analytical definitions.

**AC-009**  
Analytical results are reproducible.

**AC-010**  
No real customer PII is used.

**AC-011**  
Critical data-quality checks are documented and executed.

**AC-012**  
Business requirements can be traced to analytical outputs.
