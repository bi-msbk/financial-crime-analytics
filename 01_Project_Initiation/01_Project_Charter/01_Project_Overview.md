# Project Overview

## Project Identity

**Project Name:** Financial Crime Analytics & Fraud Detection Platform

**Fictional Organisation:** Northbridge Bank

**Business Area:** Retail Banking → Financial Crime → Fraud Analytics

**Primary Role:** Data Analyst — Financial Crime Analytics

**Project Type:** End-to-End Analytical Solution

## Project Purpose

The purpose of this project is to design and demonstrate an industry-aligned financial crime analytics solution for a fictional UK retail bank.

The solution will analyse synthetic banking transaction data to identify fraud patterns, high-risk activity, control weaknesses and opportunities to improve fraud investigation and monitoring.
