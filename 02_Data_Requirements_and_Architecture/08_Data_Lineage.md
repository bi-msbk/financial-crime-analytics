# Data Lineage

## Purpose

This document defines the conceptual lineage of data from synthetic source-like domains through validated analytical data and final business outputs.

The lineage provides traceability across:

- Synthetic data generation
- Data validation
- Analytical modelling
- SQL analysis
- Python analysis
- Fraud detection
- Machine learning
- Power BI reporting
- Management recommendations
- Investigation prioritisation

The lineage is conceptual and does not represent the internal architecture of any specific bank.
